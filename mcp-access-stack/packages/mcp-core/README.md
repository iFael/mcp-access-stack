# MCP Core

Contratos públicos e políticas compartilhadas da pilha.

O diretório foi renomeado para explicitar seu papel arquitetural; o nome npm `@vs-code-gpt/shared` foi preservado por compatibilidade.

Contém:

- contratos de workspace e navegador;
- schemas de entrada e saída;
- políticas de segurança;
- registradores das ferramentas MCP;
- erros estruturados e tipos de execução.
