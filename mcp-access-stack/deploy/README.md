# Deploy

Artefatos de Docker, releases imutáveis e tarefas Windows.

- `docker/`: Compose, Dockerfiles, inicialização, release, status e lifecycle dos hosts.
- `windows/`: instalador assinado, atualização candidate-first e validação da distribuição pública.

Consulte `docker/README.md` antes de alterar a produção. Configurações privadas e estados de implantação não são versionados.
